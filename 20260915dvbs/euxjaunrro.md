# 受精后吃避孕药有用吗？

> 更新时间：2026-09-15 (UTC+8)

受精后吃避孕药有用吗？更新时间:2022-12-27

紧急避孕药通常在同房后72小时内吃，一般同房后24～72小时形成受精卵，受精卵形成7天后着床。而在受精后的2周内，胚胎还只是个未分化的细胞团，这时用药，任何药物对胎儿的影响都只会是“全”或“无”。

1.服用紧急避孕药前已有过多次无保护性生活，且前次性生活后受精卵已经成功在子宫内着床，紧急避孕药便不能再产生避孕作用。也就是说，在已经的情况下服用紧急避孕药不会起到中断妊娠的作用。

2. 紧急避孕药只能对已发生的一次无保护性生活起到作用，服药后有再次发生无保护性生活，仍有可能怀孕。所以，在服药后至月经恢复前，不应再有无保护性生活。

3. 避孕效果与性交后至使用药物的间隔时间长短有关。性交后越早使用避孕药效果越好，随服药时间的延长，避孕失败率有增加的趋势。有一些女性朋友在使用当中未能按药品说明书上的提示进行规范使用，服药时间超过了72小时。

4. 服紧急避孕药的同时还在服用其他药物。比如在使用抗生素治疗期间，不应当选择避孕药避孕，因为抗菌药物能抑制肠道内细菌繁殖，减少激素结合物的分解，减少肝肠循环，如青霉素、氨苄西林、四环素等，可以破坏肠道内正常细菌，使得细菌活性降低，干扰甾体激素在肝脏、肠道的正常循环，导致血液中甾体激素浓度降低，从而导致避孕失败。

5. 服药后不久出现严重的、现象，或者服用紧急避孕药期间出现腹泻、发烧等情况，也会影响紧急避孕药的吸收导致避孕失败。

6. 个别女性朋友在服用方法上没有差错，但因个体差异的原因，对药物的吸收利用度不同，也可造成避孕失败。
